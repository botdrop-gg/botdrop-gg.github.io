FAQ

Do I get the full source code?

Yes. Every BotDrop product is a zip of readable Python source code with tests, a setup guide, a Dockerfile and Render/Railway/Procfile deploy configs. You host it yourself.

Can I rebrand it or use it for clients?

Yes. The commercial license lets you use, modify and rebrand the bots for your own projects and client projects, including bots you run for others. You may not resell or redistribute the template itself as a template or kit.

Do I need paid API keys?

No. The bots use public Steam, Epic and GitHub endpoints (some Steam features use public, undocumented Steam store endpoints, not the official Steam Web API; see the Terms). Discord bots need a free Discord bot token. Review Verdict for Steam can optionally use a free local Ollama model (beta) or your own LLM key.

What is tested?

Every product has unit tests and its data fetchers were run against the real public APIs. Every Docker image was built and run. Anything not live-tested, like the AI rewrite, the Twitch API path or Render/Railway deploys, is labelled beta.

What's in the bundle?

All 10 products, including the Gaming Community Kit for Discord and Stream Alert Bot. Launch price $29 until Jan 1, 2027, then $49. The products sold separately add up to $119.

What if it doesn't work for me?

30-day refund if the template doesn't work for you. Request it through Gumroad. Details: https://getbotdrop.com/refunds/

What do I need to run it?

Python 3 or Docker, a free Discord bot token (or webhook) for the Discord bots, and a free or cheap host such as your own PC, a small VPS, Render or Railway.

Why not just use a free hosted bot?

If you want zero setup, a free hosted bot is a great choice. BotDrop is for people who want control: you get the full source code, run it on your own machine or host, rebrand it with your own bot name and avatar (no "powered by" line), and your server data stays on your host instead of a bot company's servers. It keeps working even if BotDrop disappears. The trade-off is that you set it up and keep it running yourself.

Is there a subscription?

No. You pay once on Gumroad and keep what you bought. There is no monthly fee from BotDrop. Your only ongoing cost is wherever you choose to run it, which can be your own PC for free.

Do I own the source? Can I rebrand it?

You get the full source code and can modify and rebrand it for your own and client projects under the BotDrop Commercial License. You may not resell the template itself.

What if my PC is off?

If the bot runs on your own PC, it stops when the PC is off or asleep, and starts again when you run it again. To keep it online 24/7, run it on an always-on computer (like a Raspberry Pi) or a small paid host. Our deploy guide at getbotdrop.com/deploy/ walks you through it step by step.

Where can I host it for free or cheap?

Free: your own PC (only while it is on) or Oracle Cloud's Always Free server (free, but harder to set up). Cheap: Render background worker about $7/month, Railway Hobby $5/month, fly.io from about $2/month, or a small VPS. Prices checked October 2026; see getbotdrop.com/deploy/ for the honest pros and cons of each.
