FAQ

Do I get the full source code?

Yes. Every BotDrop product is a zip of readable Python source code with tests, a setup guide, a Dockerfile and Render/Railway/Procfile deploy configs. You host it yourself.

Can I rebrand it or use it for clients?

Yes. The commercial license lets you use, modify and rebrand the bots for your own projects and client projects, including bots you run for others. You may not resell or redistribute the template itself as a template or kit.

Do I need paid API keys?

No. The bots use public Steam, Epic and GitHub endpoints (some Steam features use public, undocumented Steam store endpoints, not the official Steam Web API; see the Terms). Discord bots need a free Discord bot token. Review Verdict for Steam can optionally use a free local Ollama model (beta) or your own LLM key.

What is tested?

Every product has unit tests and its data fetchers were run against the real public APIs. Every Docker image was built and run. Anything not live-tested, like the AI rewrite, the Twitch API path or Render/Railway deploys, is labelled beta.

A Windows 10 or 11 PC for the one-click launcher (no coding), a free Discord bot token or webhook for the Discord bots, and your Discord server. To run it 24/7, a host such as Render or Railway for about $5 to $8 a month. Developers can also run any bot with Python 3 or Docker.

If you want zero setup, a free hosted bot is a great choice. What if my PC is off?

If the bot runs on your own PC, it stops when the PC is off or asleep, and starts again when you run it again. Tick Start with Windows in the launcher so it comes back when you log in.
