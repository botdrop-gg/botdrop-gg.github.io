Check your download (SHA-256 checksums)

A checksum is a file’s fingerprint. If even one byte of a file changes, its SHA-256 checksum changes completely. Compare the checksum of the file you downloaded with the one below: if they match, you have exactly the file we published. Last updated: October 18, 2026.

Honest note: our Windows launchers are not code-signed yet, so Windows SmartScreen will probably show “Windows protected your PC” the first time you open one. Check the checksum first, then click More info and Run anyway. More about the warning. The Gaming Community Kit launcher (including Kit 2.0) was tested on a real Windows PC; the other bots’ launchers are beta.

How to check a file on Windows

  1. Open the folder with the downloaded file. Click the address bar at the top, type powershell and press Enter.
  2. Type this (with your file’s name) and press Enter:
    Get-FileHash .\BotDrop-Kit-windows.exe -Algorithm SHA256
    Or, in Command Prompt:
    certutil -hashfile BotDrop-Kit-windows.exe SHA256
  3. Compare the long code it prints with the one in the table below. Capital or small letters don’t matter.

Linux: sha256sum BotDrop-Kit-linux · Mac: shasum -a 256 BotDrop-Kit.zip

If it doesn’t match, don’t run the file. Download it again from your Gumroad library (or your Kit email for the free Radar). If it still doesn’t match, email hello@getbotdrop.com. When we release an update, the checksums change and this page is updated with the new files (see the changelog).
