Changelog

What changed in BotDrop products, newest first. Updates are free: re-download from your Gumroad library. See how updates work.

October 18, 2026: Gaming Community Kit 2.0.1

  • First posts right after /setup: once /setup has created the channels, the bot checks free games, deals and patch notes straight away, so the first posts appear within seconds. No restart needed. A /setup check and a scheduled check can’t post the same item twice.
  • If Discord refuses a post because the bot is missing Send Messages or Embed Links in a channel, the log now shows one clear line per server and channel (no error dump), and the items are kept and posted once the permissions are fixed.
  • 125 unit tests (6 new). Tested live on a Discord test server: the first posts appeared about 4 seconds after /setup. Re-download the Kit from your Gumroad library to get it.

October 18, 2026: Gaming Community Kit 2.0

  • Saved strikes: strikes are stored on your machine, survive restarts, and the new /strikes view and /strikes clear commands show and reset them.
  • Steam games by name: type “Hades” instead of an app ID in /patchnotes, /players, the config file and the dashboard, with suggestions as you type.
  • Local web dashboard (127.0.0.1 only, token-protected): switch modules, edit settings, see strikes and the mod log.
  • /setup wizard: creates the bot’s channels and roles and is safe to run again (no duplicates).
  • Saved strikes, Steam games by name, the dashboard and /setup were tested live on a real Discord test server. Fixes from that test: deal alerts are no longer re-posted after a restart; games found before /setup runs are kept and posted at the next scheduled check once the channels exist (since 2.0.1, /setup posts them right away); the bot only posts to its own configured channels; and it prints the invite link at start-up if it lacks the new permissions.
  • BETA, not yet fully tested on a real Discord server: a verification gate with an optional minimum account age (off by default; a real new member clicking the button is untested) and anti-nuke lite (off by default; a real raid is untested). 119 unit tests in 2.0, including mocked Discord objects and real HTTP tests of the dashboard.
  • Launcher: new Open dashboard button and a /setup step. Tested on a real Windows PC on Oct 18, 2026: the dashboard opened, the bot connected, and after /setup the feed posts went through. The invite link now also asks for Manage Channels, Manage Roles, View Audit Log and Manage Webhooks.

October 18, 2026

  • Free Games Radar is now free. Get it on the Free Games Radar page by confirming your email. It’s still in the bundle.
  • New: SHA-256 checksums for every download, and a plain explanation of the Windows SmartScreen warning in the setup guide.

October 17–18, 2026

  • Discord delivery fix in the Gaming Community Kit, Wishlist Deal Alert, Patch Tracker, Player Count Tracker, What to Play Tonight, Stream Alert Bot, Intel for Steam and Free Games Radar. A post now only counts as sent when Discord confirms it. The bot saves “already posted” only after that, so a failed post is tried again on the next run instead of being skipped. Discord rate limits are retried after the wait Discord asks for, and failures are reported in plain words without printing your webhook link. New tests cover each case. Re-download from your Gumroad library to get it.
  • Launcher v4 (Windows and Linux): the invite step waits until your bot has really joined your server before it lets you continue, and the status window shows which server the bot is online in, or a warning with the invite link if it isn’t in a server yet.

October 16, 2026

  • One-click launchers for every product: a Windows .exe and a Linux build that walk you through setup and run the bot with a status window (and a tray icon on Windows). Tested on a real Windows PC for the Gaming Community Kit; beta for the other bots and on Linux.
  • Stream Alert Bot released. Posting into a real Discord server was tested live (a YouTube upload and a Twitch go-live alert, with no duplicates on the next run).
  • Intel for Steam: Indie Dev Toolkit released (sold separately, not in the bundle).
  • Setup guide published; the Render steps were tested end to end with a new account.

October 15, 2026

  • Gaming Community Kit for Discord released.
  • Gaming Community Kit and Mod Bot live-tested on a real Discord server. That run found 4 bugs, including a name clash that broke auto-mod on the first deleted message and a crash in player tracking, which were fixed before release.
