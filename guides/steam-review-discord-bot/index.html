How to Set Up a Steam Review Discord Bot (Free)

By BotDrop · Updated November 25, 2026 · Free guide, no purchase needed

If you make a game on Steam, new reviews are some of the fastest feedback you'll get. A Steam review Discord bot posts each new review into a channel, so you and your team see it as it lands instead of refreshing the store page. This guide starts with the free way, running a small script on your own computer, then explains webhooks versus bots and when a bigger tool is worth it.

What you'll end up with

Every few minutes, a new message appears in a Discord channel for each new Steam review of the game you pick:

  • 👍 Recommended or 👎 Not recommended, in green or red
  • An excerpt of the review (up to 300 characters)
  • The reviewer's playtime when they wrote it, and the review's language
  • A link to the review on Steam
  • Steam's own totals: number of reviews, % positive and Steam's label (for example “Very Positive”)

Before you start

  • The game's Steam App ID. Open the game's store page and look at the address. In store.steampowered.com/app/620/Portal_2/ the App ID is 620.
  • A Discord server where you can manage webhooks. If it's your server, you already can. Otherwise you need the Manage Webhooks permission.
  • A computer that can run Python 3.9 or newer: Windows, Mac, Linux or a Raspberry Pi.

You don't need a Steam API key or a Steamworks account. Steam reviews are public, so this works for any game on Steam: yours, a rival's, or one your community plays.

Step 1: Make a private channel and a webhook

A webhook is a special link that lets a program post messages into one channel. Reviews can be blunt, so most developers use a private channel just for the team, such as #steam-reviews.

  1. Open Server Settings → Integrations → Webhooks.
  2. Click New Webhook (Discord's help page calls it Create Webhook).
  3. Give it a name like “Steam Reviews”, choose your review channel, and click Copy Webhook URL.

Keep the webhook URL secret. Anyone who has it can post in that channel. If it leaks, delete the webhook and make a new one. More in our beginner guide to Discord webhooks.

Step 2: Download Review Pulse

Go to the Review Pulse page on GitHub. Above the list of files, click Code, then Download ZIP. Unzip it somewhere easy to find, like your Documents folder.

Step 3: Install Python (if you don't have it)

On Windows, Python's own docs say to install it from the Microsoft Store or from python.org/downloads. When it's done, open a terminal, type python and press Enter to check it works (type exit() to leave). On a Mac or Linux, type python3 --version in Terminal. If you don't see a version number, install Python 3 from python.org.

Step 4: Add your settings

In the unzipped folder, open .env.example in a text editor. Fill in the two empty lines and leave the rest as it is:

STEAM_APP_ID=620
DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/...your link...
CHECK_EVERY_MINUTES=15

Save it in the same folder as .env (just a dot and “env”). In Windows Notepad, set Save as type to All files, or it will be saved as .env.txt and the script won't find it.

Step 5: Start it

Open a terminal in that folder (Command Prompt or PowerShell on Windows, Terminal on a Mac) and run:

python review_pulse.py

On a Mac or Linux, type python3 instead of python. With CHECK_EVERY_MINUTES=15 it keeps running and checks every 15 minutes. Leave the window open.

What to expect: the very first check posts just the 3 newest reviews, so you can see it working. Older reviews are never dumped into your channel. After that, only new reviews are posted, each one once. It remembers what it posted in a file called review_pulse_state.json, so keep that file.

BETA: running on Windows. Review Pulse was tested live on Linux: it posted real reviews into a real Discord channel on Oct 19 and Oct 25, 2026, with no duplicates on the next run. On Nov 25, 2026 we checked again that it still reads live reviews from Steam's review API (that check didn't post to Discord). It hasn't been run on Windows yet. It's plain Python with no extra packages, so it should work, but the Windows steps above (Microsoft Store Python, Notepad) are untested.

Keeping it running (even 24/7, for $0)

Review Pulse runs while that window is open and the computer is on and awake. Leave your PC on and it runs 24/7 at no cost. If it's off for a while, nothing is lost: when you start it again, it posts the reviews it missed (it reads the 300 newest each check and sends up to 20 per check; the rest go out on the next one).

  • An old laptop or a Raspberry Pi works well as an always-on machine. On Linux or a Pi, you can let the system run it every 15 minutes instead: set CHECK_EVERY_MINUTES=0 in .env and add a cron line such as */15 * * * * cd /path/to/review-pulse && /usr/bin/python3 review_pulse.py >> pulse.log 2>&1.
  • Docker BETA: a Dockerfile is included, but it hasn't been built in our tests yet.

Option 2: Webhook or a full bot?

People search for a “Steam review Discord bot”, but for review alerts a webhook is usually all you need. Here's the difference:

Webhook (what Review Pulse uses)Full Discord bot
What it isA posting-only link into one channelAn app account you create in the Discord Developer Portal and invite to your server
SetupCopy one URL from Server SettingsCreate an app, keep a bot token safe, pick permissions, invite it
Can itPost messages, with its own name and avatarPost, answer slash commands, react to members, read channels it's allowed to see
Good forAlerts: new reviews, patch notes, uploadsInteractive features, like a command that shows your review score on demand

Start with the webhook. If you later want commands or other bot features, our guide to hosting a Discord bot on your own PC walks through creating a bot and keeping its token safe.

Tips for a useful review channel

  • Keep it private at first. A team-only channel lets you read harsh reviews calmly before anyone reacts in public.
  • Don't ping everyone. Review Pulse never pings anyone, even if a review contains @everyone.
  • Every 15 minutes is plenty. Steam's review list can lag. In our test one response was about an hour behind, so reviews sometimes arrive in a small burst. They're real new reviews, not repeats.
  • Totals can differ slightly from your store page. The totals in each post count all languages and purchase types, while the store page's headline number may be filtered.
  • Answer reviews on Steam, not in Discord. Each post links to the review. Steamworks lets developers write an official developer response under a review, but Valve's own advice is that not every review needs one.
  • One game per copy. Review Pulse watches one game. To watch two, use two folders, each with its own .env.

Questions

Do I need a Steam API key?

No. Review Pulse reads Steam's public review API, which needs no key. Valve can change or limit that API at any time, so keep checks to every few minutes or more.

Can I track a game that isn't mine?

Yes. Reviews are public, so any App ID works.

Will it flood my channel with old reviews?

No. The first check posts the 3 newest reviews so you can see it working, and everything older is skipped for good.

Does it need a paid server to run 24/7?

No. It runs 24/7 on your own PC as long as the PC is on and awake. An old laptop or a Raspberry Pi works too.

What if Discord is down when a review comes in?

A review only counts as posted after Discord accepts it, so anything that fails is tried again on the next check.
