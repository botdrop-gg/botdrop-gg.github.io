How to Set Up a Game Deals Discord Bot (Free)

By BotDrop · Updated November 25, 2026 · Free guide, no purchase needed

A good deals channel is one of the most-read channels in a gaming Discord: free games to grab, big discounts on games your group actually plays, and a heads-up when a Steam sale starts. You can run a game deals Discord bot for free on your own PC. This guide shows how, then covers Discord's built-in tools for sale days and when an all-in-one bot is worth it.

What a good deals channel posts

  • Free-to-keep games. Games that are 100% off for a limited time and stay in your library after you claim them.
  • Big discounts on games your community plays, not every discount on Steam. A short watch list beats a firehose that people mute.
  • Sale reminders. A heads-up when a big Steam sale starts, so friends can plan what to buy together.

Make a channel called #deals (and #free-games if you want them apart), then follow the steps below.

Option 1: Free, on your own PC

Both parts below post through a Discord webhook: a special link that lets a program post into one channel. No bot account or token is needed.

Step 1: Make a webhook for your deals channel

  1. Open Server Settings → Integrations → Webhooks. You need the Manage Webhooks permission.
  2. Click New Webhook (Discord's help page calls it Create Webhook).
  3. Name it something like “Deals”, pick #deals, and click Copy Webhook URL.

Keep the webhook URL secret. Anyone who has it can post in that channel. If it leaks, delete the webhook and make a new one. More in our beginner guide to Discord webhooks.

Step 3: Steam deals for your watch list, with a small script

For discounts, pick the games your community actually plays. This free Python script checks their Steam prices and posts to your webhook when one is at least 50% off, or at or below a target price you set. It posts each sale once, and again only if the price drops further.

  1. Find each game's App ID. It's the number in the store address: in store.steampowered.com/app/413150/Stardew_Valley/ it's 413150.
  2. Install Python 3 if you don't have it. On Windows, Python's own docs say to install it from the Microsoft Store or python.org/downloads.
  3. Save the script below as steam_deals_channel.py in its own folder, and change WATCH to your games.
# steam_deals_channel.py: posts Steam deals from your server's watch list to a Discord channel.
# Needs Python 3 only (no extra packages). Run it every few hours.
import json, os, urllib.request

WEBHOOK = os.environ["DISCORD_WEBHOOK_URL"]  # keep it out of the code
WATCH = {1174180: None, 1086940: 45.00, 413150: None}  # App ID: your target price, or None
MIN_DISCOUNT = 50          # games without a target are posted at this % off or more
COUNTRY = "us"             # your Steam store region
SEEN_FILE = "deals_seen.json"  # remembers what was already posted
API = "https://store.steampowered.com/api/appdetails?appids={}&cc={}&filters=basic,price_overview"

def call(url, data=None):
    req = urllib.request.Request(url, data=data, headers={
        "User-Agent": "steam-deals-channel-script", "Content-Type": "application/json"})
    with urllib.request.urlopen(req, timeout=20) as r:
        return r.read()

seen = json.load(open(SEEN_FILE)) if os.path.exists(SEEN_FILE) else {}
for app, target in WATCH.items():
    info = json.loads(call(API.format(app, COUNTRY)))[str(app)]
    data = (info.get("data") or {}) if info.get("success") else {}
    price = data.get("price_overview")
    if not price or price["discount_percent"] == 0:
        seen.pop(str(app), None)   # not on sale: the next sale gets posted again
        continue
    now = price["final"] / 100
    if target is not None:
        good = now <= target
    else:
        good = price["discount_percent"] >= MIN_DISCOUNT
    last = seen.get(str(app))
    if good and (last is None or now < last):  # once per sale, again only if it drops further
        link = f"https://store.steampowered.com/app/{app}/"
        msg = (f"💸 **{data.get('name', app)}** is {price['discount_percent']}% off: "
               f"{price['final_formatted']}\n<{link}>")
        call(WEBHOOK, json.dumps({"content": msg[:2000]}).encode())
        seen[str(app)] = now
json.dump(seen, open(SEEN_FILE, "w"))

In WATCH, put a price (like 45.00) to post only at or below that price, or None to post when the game is at least MIN_DISCOUNT% off. Set COUNTRY to your Steam store region, because prices differ by region.

Run it: set the webhook as an environment variable (on Windows: setx DISCORD_WEBHOOK_URL "your-webhook-url", then open a new terminal window), and run python steam_deals_channel.py in that folder. To repeat it on Windows, create a task in Task Scheduler and, in the task's trigger, tick Repeat task every and choose 1 hour. On Linux or a Raspberry Pi, use a cron line like 0 */3 * * * cd ~/deals && DISCORD_WEBHOOK_URL=your-webhook-url python3 steam_deals_channel.py to check every 3 hours.

BETA: this script. On Nov 25, 2026 we ran it against Steam's live store data, with a local test endpoint standing in for Discord. It posted the two watched games that were on sale and skipped the one at full price. A second run posted nothing new. We haven't sent it to a real Discord channel or tried it on Windows yet. Discord webhooks accept this same {"content": …} format, up to 2,000 characters. The price data comes from a public Steam store endpoint that the store uses itself, but Valve doesn't formally document it for outside developers, so it could change. Keep the list short and check every hour or few hours, not every minute.

Turn each one into a Discord scheduled event: click the arrow next to your server's name, choose Create Event, pick Somewhere Else, enter #deals or the Steam store link as the location, fill in the date, and click Create Event. Members who click Interested get a notification when the event starts. You need the Create Events permission. One catch: Discord removes events that aren't started soon after their scheduled time, so start it yourself from the Events list when the sale begins.

Follow an announcement channel

If another server you're in posts deals in an announcement channel (a megaphone icon next to its name), click Follow and pick your #deals channel. Every post they publish then shows up in your server too. You need the Manage Webhooks permission in your server. Only follow sources you trust, since their posts appear in your server.

Tips for a deals channel people don't mute

  • Don't ping everyone. Make a @deals role that members can pick, and only mention it for the big ones.
  • Keep the watch list short. Ten games your group plays beat a hundred random ones.
  • Say which region the prices are for. Steam prices differ by country, so a US price may not match what a member in another region sees.
  • Use a 50% minimum or real targets. Small discounts happen all the time and fill the channel with noise.
  • Keep free games apart if you can. A separate #free-games channel is easy to follow, even for members who mute deals.

Questions

Is a game deals Discord bot free?

Yes, the setup in Option 1 costs nothing. Free Games Radar is free for your email, the script is free, and both run on your own PC.

Does it need a paid server to run 24/7?

No. It runs 24/7 on your own PC as long as the PC is on and awake. An old laptop or a Raspberry Pi works too.

Do I need a Steam API key?

No. The script, Free Games Radar, the Kit's deals feed and Wishlist Deal Alert all use public Steam store data that needs no key.

Which stores does it cover?

The deals script and BotDrop's deal alerts watch Steam prices. Free Games Radar covers free-to-keep games on Epic and Steam.

Will it post the same deal twice?

No. Each tool remembers what it posted. The script posts a sale again only if the price drops further, or after the game goes back to full price and goes on sale again.
